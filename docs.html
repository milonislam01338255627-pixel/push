৩. নোটিফিকেশন পাঠান


ড্যাশবোর্ডে টাইটেল ও মেসেজ লিখে "পাঠান" চাপুন। ছবি আর লিংক চাইলে ঐচ্ছিক ঘরে দিন।


  • ছবি: ছবির সরাসরি URL (https://...jpg বা png) দিন।
  • লিংক: না দিলে ভিজিটরের ট্যাপে আপনার ওয়েবসাইটই খুলবে।



API দিয়ে পাঠানো




ফিল্ডবিবরণ


titleআবশ্যক। সর্বোচ্চ ১০০ অক্ষর।


bodyআবশ্যক। সর্বোচ্চ ৩০০ অক্ষর।


urlঐচ্ছিক। ক্লিকে যে লিংকে যাবে।


imageঐচ্ছিক। বড় ছবির URL।


iconঐচ্ছিক। ছোট আইকনের URL।

কাজ না করলে


  • ওয়েবসাইট HTTPS-এ আছে কিনা দেখুন।
  • pushsaas-sw.js ফাইল রুটে আছে কিনা দেখুন। ঠিকানা/pushsaas-sw.js খুললে এক লাইনের কোড দেখা যাওয়া উচিত।
  • Chrome-এ সাইটের নোটিফিকেশন অনুমতি "Block" করা থাকলে সেটা "Allow" করুন।
  • iPhone-এ সাইটটা হোম স্ক্রিনে যোগ করে খুলুন।
  • ড্যাশবোর্ডে প্ল্যানের মেয়াদ আছে কিনা দেখুন।
